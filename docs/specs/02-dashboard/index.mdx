# 02 儀表板

登入後的第一頁。系統依使用者在各任務的角色給他一種對應的版面，把他的任務彙整在一起，並讓他一步回到標記或審核。

這個模組**只讀不寫**：PRD §權限矩陣 給儀表板的只有 `R`。它顯示的數字來自 03 任務管理、04 標記作業與 05 資料集，計算規則由那些模組擁有。

## Logic Flow

儀表板本身不做事——它只做一次「你是誰、你在這些任務裡是什麼角色」的判斷，然後把人帶到他真正該去的地方；所以每一段跨頁的流程，結尾大多是離開這一頁（引自[規格 02-01 §業務流程](./01-dashboard.mdx#業務流程)的核心洞察；分段四的 `X4 → P1` 是這句話唯一的例外，因為它講的不是離開、是回來之後這一頁要顯示什麼）。本模組只有一個規格頁（02-01），所以下面沒有「頁面與頁面之間」的連接，只有「這一頁與其他模組之間」的連接。

這一節只畫頁面之間怎麼走，以及決定往哪一頁走的判斷；同一頁裡的版面切換（系統管理員、專案負責人、審核員、標記員、還沒有任務角色，這五種版面的選擇）不跨頁，不畫成連線。業務流程裡的「讀取任務角色時的載入與失敗」也完全不跨頁——骨架佔位與讀取失敗的錯誤畫面都停在這一頁，所以不出現在下面的圖與清單裡，規則仍在[規格 02-01 §業務流程](./01-dashboard.mdx#業務流程)本身與[§卡控機制](./01-dashboard.mdx#卡控機制)。離開這一頁的連線一律畫，不論規則寫在哪一份規格；回到這一頁的連線只在 02-01 自己定了「回來之後這一頁顯示什麼」時才畫——[§審核員任務列的摘要數字從哪裡來](./01-dashboard.mdx#審核員任務列的摘要數字從哪裡來)第 12 條是（畫成分段四的 `X4 → P1`），而個人設定回來那一條的唯一效果（語言不變）由[§導覽、語言與登出不在這一頁](./01-dashboard.mdx#導覽語言與登出不在這一頁)第 2 條歸給規格 07-01、第 3 條只留「自己的內容跟著換語言」給這一頁，所以不畫。每一條連線都對回規格的條文，規格裡找不到出處的連線不畫；唯一沒有規格出處的是起訖連線（S 接上的線），只標出流程從哪裡開始。

### 節點

同一個節點出現在不同分段時用同一個編號。

- 起訖
  - S 開始：使用者登入成功，進入儀表板
- 頁面（矩形）
  - P1 [02-01 儀表板](./01-dashboard.mdx#業務流程)（依身分顯示其中一種版面：全平台、專案負責人、審核員、標記員或還沒有任務角色的行動入口，規則見[§規格「這一頁顯示哪一種版面」](./01-dashboard.mdx#這一頁顯示哪一種版面)）
- 判斷（菱形）
  - D1 已登入且系統角色有效？
  - D2 這個任務還有沒提交的資料嗎？
  - D3 推導得出可處理的審核單位嗎？
- 其他流程或外部系統（雙邊框）
  - X1 [01-01 登入頁](../01-account/01-login.mdx#業務流程)
  - X2 [03-01 任務列表](../03-task-management/01-task-list.mdx#業務流程)
  - X3 [04-01 標記清單](../04-annotation/01-annotation-list.mdx#業務流程)
  - X4 [04-02 標記工作區](../04-annotation/02-annotation-workspace.mdx#業務流程)
  - X5 [01-04 個人設定頁](../01-account/04-profile.mdx#業務流程)

### 分段一：進入儀表板與行動入口

卡 A（開始建立任務）不引規格 07-01 §進入模組的條件：那一條只管「標記作業」與「資料集分析」兩個模組，任務管理本來就不被任務角色擋下，不需要例外；卡 B、C（開始標記、開始審核）去的是真的被那一條管到的模組，保留這個引用。

1. S → D1（起訖連線，無規格條文）
2. D1 否 → X1 登入頁（02-01 業務流程「進入儀表板拿到自己的版面」E1；§卡控機制「系統角色不在允許清單裡」「使用者沒有登入」；§驗收標準「角色無效時導向登入頁」「未登入時導向登入頁」）
3. D1 是 → P1 儀表板（02-01 業務流程「進入儀表板拿到自己的版面」主流程 1～3；§規格「這一頁顯示哪一種版面」1～3）
4. P1（還沒有任務角色的版面）按卡 A「開始建立任務」→ X2 任務列表（02-01 業務流程 A1；§規格「還沒有任務角色的人看到什麼」2、3、7；03-01 自己的引言「這一頁是任務管理模組的進入點」）
5. P1 按卡 B「開始標記」→ X3 標記清單（02-01 業務流程 A1；§規格「還沒有任務角色的人看到什麼」2、3、7；04-01 §規格「兩種入口並存」第 1 條「這一頁是標記模組的入口頁」；02-01 §驗收標準「三張卡的按鈕都走到模組入口頁」；規格 07-01 §進入模組的條件 第 4 條例外；規格 07-01 §驗收標準「從儀表板行動入口卡進入不被擋下」）
6. P1 按卡 C「開始審核」→ X3 標記清單（同上條款；02-01 §規格「還沒有任務角色的人看到什麼」3，「審核的入口」與卡 B 同指 04-01）

### 分段二：系統管理員與專案負責人的清單入口

1. P1（系統管理員或專案負責人版面）點「等待 IAA 確認」數值 → X2 任務列表，已套用「等待 IAA 確認」狀態篩選（02-01 §規格「「等待 IAA 確認」這張卡是一個入口」1～4；§驗收標準「等待 IAA 確認可用滑鼠點」「等待 IAA 確認可用鍵盤觸發」「等待 IAA 確認的數字與清單一致」「等待 IAA 確認為零仍是入口」）
2. P1 點「查看全部」→ X2 任務列表，不套篩選，範圍依登入者身分（02-01 §規格「「查看全部」去哪裡、看得到誰的任務」1～7；§驗收標準「系統管理員查看全部得到全平台」「專案負責人查看全部只得到自己的」）

### 分段三：標記員的快速繼續

1. P1（標記員版面）點某列「快速繼續」→ D2（02-01 業務流程「從儀表板回到標記工作」觸發、前置條件、主流程 1～2）
2. D2 找到了 → X4 標記工作區，帶任務、資料與標記員身分（主流程 3；§驗收標準「快速繼續開第一筆沒提交的資料」）
3. D2 全部已提交 → X3 標記清單，該任務、不指定某一筆；「快速繼續」仍可見可按（A1；§已確認決議 Q13；§驗收標準「全部已提交時快速繼續到清單」）
4. P1 點某列「快速繼續」以外的地方 → X3 標記清單，該任務（A2；§驗收標準「點標記員任務列其他地方到清單」）

### 分段四：審核員的快速審核

1. P1（審核員版面）點某列「快速審核」→ D3（02-01 業務流程「從儀表板回到審核工作」觸發、前置條件、主流程 1～2；§規格「「快速審核」要開哪一個審核單位」1～4）
2. D3 推導得出 → X4 標記工作區，帶任務、樣本、標記員身分、審核員身分與標記階段五項（主流程 3；§規格同節第 5 條；§驗收標準「快速審核開可處理的審核單位」）
3. D3 是空的 → X3 標記清單，該任務、不指定某一筆，顯示明確的空狀態說明；不開任務的第一筆，也不開任何已定稿的唯讀單位（A1；§規格同節第 7、8 條；§驗收標準「沒有可處理單位時到清單並說明」「沒有可處理單位時不開已定稿的」）
4. P1 點某列「快速審核」以外的地方 → X3 標記清單，該任務（A2；§驗收標準「點審核員任務列其他地方到清單」）
5. X4 → P1 儀表板，審核員在工作區改了某個審核單位的狀態後回來，摘要與進度條立刻反映新狀態，重新整理後也一致（02-01 §審核員任務列的摘要數字從哪裡來 第 12 條；§驗收標準「改過狀態後回來立刻反映」）

### 分段五：側欄導覽離開儀表板

側欄本身的規則屬規格 07-01，這裡只列從儀表板這一頁離開、進到另一個模組或登入頁的三條連線。

1. P1 點側欄「個人設定」→ X5 個人設定頁（規格 07-01 §導覽項目與可見性「個人設定對 01-04」；02-01 §驗收標準「換頁再回來語言不變」的 When「前往個人設定或帳號頁面再回到儀表板」）
2. P1（專案負責人版面）點側欄「標記作業」→ X3 標記清單（02-01 §規格「這一頁顯示哪一種版面」第 3 條後方附註「他要標記得從側欄進入標記作業」；§邊界情況「平台成員同時是專案負責人與標記員」；§Q&A 同義）
3. P1 點側欄「登出」→ X1 登入頁（02-01 §導覽、語言與登出不在這一頁 第 1 條，側欄導覽與登出的規則都在規格 07-01，這一頁只是使用它；規格 07-01 §登出 第 1 條）

本模組盤點過的每一條跨頁連接都找得到規格出處，沒有找不到出處而不畫的連線。
