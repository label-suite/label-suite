# 07 共用介面

所有登入後的頁面共用的外框：側欄導覽、工作頁籤、被擋下時看到的兩種畫面，以及哪些事會通知人。每一個使用者都會用到，所以這個模組的術語與角色寫法是其他模組的基準。
四頁都不是獨立頁面：前三頁的畫面出現在每一個模組頁裡，07-04 定的是一份跨模組的清單、本身沒有畫面。

## Logic Flow

共用介面的四頁都不是獨立頁面，所以這一節畫的是它們把人帶去哪一頁。側欄把人送進六個模組與登入頁，其中第三個導覽項與「資料集分析」要先看任務角色：第三個導覽項讀作「例外處置」時進任務列表，其餘依[規格 07-01](./01-sidebar.mdx#進入模組的條件) §進入模組的條件 的「任一個」任務有沒有任務角色（第 1 條），決定進標記清單還是被擋回儀表板，「資料集分析」看目前任務、進不去就回任務列表（第 2、3 條）。工作頁籤在開啟、切換與關閉時決定內容區換成哪一頁：切回一個頁籤時權限或資料已經失效，那個頁籤就換成無權限或找不到的畫面（[規格 07-02](./02-workspace-tabs.mdx#權限或資料失效) §權限或資料失效 第 1、2 條）。那兩種畫面只有一個返回操作，去哪裡由各模組自己指定（[規格 07-03](./03-denied-and-not-found.mdx#返回操作的去處) §返回操作的去處 第 1 條）。[規格 07-04 通知事件](./04-notification-events.mdx#業務流程)本身沒有畫面，不成一個節點：它的兩個消費端是側欄的通知清單（在 P1 裡）與儀表板的「最近提醒」，而點側欄的某一則通知會到哪一頁規格沒有寫，列為缺口一。

這一節只畫頁面之間怎麼走，以及決定往哪一頁走的判斷；同一頁裡的操作細節看各規格的業務流程。連線依方向分三類判：離開本模組一律畫，進入與返回只在本模組自己的規格定了那個入口、或定了「回來之後這一頁顯示什麼」時才畫，模組內兩頁之間的移動本來就要畫。每一條連線都對回規格的條文，規格裡找不到出處的連線不畫，理由逐條寫在最後那個缺口摺疊區塊；三類判準逐條盤點的結果，列在它前面那個摺疊區塊。唯一沒有規格出處的是起訖連線（S 接上的線），它只標出流程從哪裡開始。這個模組沒有 E 結束節點：側欄與頁籤列出現在每一個登入後的頁面（[規格 07-01](./01-sidebar.mdx#導覽項目與可見性) §導覽項目與可見性 第 1 條、[規格 07-02](./02-workspace-tabs.mdx#頁籤列的位置) §頁籤列的位置 第 1 條），使用者從任何一頁用它們換到另一頁，每一條出口不是到別的模組的頁面（X1～X9、X11）或瀏覽器的新分頁（X10），就是留在目前的頁籤或那兩種畫面上，沒有一個是模組的自然終點。

### 分段一：側欄直接進的模組與登出

這四個導覽項與登出不看任務角色；「系統管理」只有系統管理員看得到，平台成員的側欄沒有它（[規格 07-01](./01-sidebar.mdx#導覽項目與可見性) §導覽項目與可見性 第 2、3 條），看不到的項目點不到，不是一條移動。

1. S → P1（起訖連線，無規格條文；07-01 §業務流程「從側欄進入模組」觸發是這個入口）
2. P1 點「儀表板」→ X1 儀表板（07-01 §導覽項目與可見性 第 1 條與該節「儀表板對 02」的註；07-01 §業務流程「從側欄進入模組」主流程第 2 步）
3. P1 點「任務管理」→ X2 任務列表（07-01 §導覽項目與可見性 第 1 條與該節「任務管理對 03」的註；03-01 §業務流程「進到任務列表」觸發）
4. P1 點「個人設定」→ X3 個人設定（07-01 §導覽項目與可見性 第 1 條與該節「個人設定對 01-04」的註）
5. P1 系統管理員點「系統管理」→ D1（07-01 §導覽項目與可見性 第 3 條；§系統管理的次選單 第 1、5 條）
6. D1 否 → X4 使用者管理（在手機或側欄已收合：直接進入使用者管理，不展開次選單；07-01 §系統管理的次選單 第 5 條；§驗收標準「手機點擊系統管理直接進入使用者管理」「側欄收合後點擊系統管理」；06-01 §規格 的「存取與分頁切換」第 1 條）
7. D1 是 → X5 角色設定（展開次選單，點「角色設定」直接進入角色設定頁，不經過使用者管理頁；07-01 §業務流程「從側欄進入模組」A1；§系統管理的次選單 第 1、2 條；§驗收標準「展開系統管理次選單直達角色設定」；06-02 §怎麼進來、誰進得來 第 1 條）
8. P1 點「登出」→ X6 登入頁（結束這次的登入狀態；07-01 §業務流程「登出」主流程第 1～2 步；§登出 第 1 條；§驗收標準「登出後回到登入頁」）

### 分段二：看任務角色的兩個導覽項

第三個導覽項讀作「標記作業」「審核作業」或「例外處置」，名稱依任務角色變，但它指向的模組都是 04（[規格 07-01](./01-sidebar.mdx#導覽項目與可見性) §導覽項目與可見性 的「它指向的模組不變」）；落點則依名稱分。

1. P1 點第三個導覽項 → D2（07-01 §導覽項目與可見性 第 4～6 條；§進入模組的條件 的「第 1 條進入標記作業之後的落點依第三個導覽項的名稱分」）
2. D2 是 → X2 任務列表（讀作「例外處置」：進到任務列表，不進標記清單；他處置例外的入口在任務詳情的最終例外池；07-01 §卡控機制 的「進到任務列表，不進標記清單」；§驗收標準「專案負責人進得去標記作業」「只當專案負責人的人看到例外處置」；§已確認決議 Q15、Q18）
3. D2 否 → D3（讀作「標記作業」或「審核作業」；07-01 §導覽項目與可見性 第 4、6 條；§進入模組的條件 第 1 條）
4. D3 是 → X7 標記清單（連結不帶任務，但在網址帶入口標記，由那一頁列出他有標記員或審核員角色的任務讓他挑；07-01 §進入模組的條件 第 1 條；§卡控機制 的「連結不帶任務，但在網址帶入口標記」；§驗收標準「點標記作業進到的是清單頁」「在別的任務有角色時點擊標記作業」；§已確認決議 Q16、Q17；04-01 §路由上下文與回退 第 11 條）
5. D3 否 → X1 儀表板（擋下，回到儀表板並顯示說明；07-01 §業務流程「從側欄進入模組」E2；§進入模組的條件 第 3、5 條，從側欄點導覽項不適用第 4 條的放寬；§驗收標準「沒有任務角色時點擊標記作業」）
6. P1 點「資料集分析」→ D4（07-01 §進入模組的條件 第 2 條）
7. D4 是 → X8 分析列表（07-01 §進入模組的條件 第 2 條；§業務流程「從側欄進入模組」A2；05-01 §業務流程「進到分析列表」主流程第 2、4 步）
8. D4 否 → X2 任務列表（擋下，回到任務列表並顯示說明；07-01 §業務流程「從側欄進入模組」E2；§進入模組的條件 第 3 條；§卡控機制 的「擋下進入資料集分析，回到任務列表並顯示說明」；§驗收標準「沒有任務角色時點擊資料集分析」；§已確認決議 Q9）

### 分段三：開啟頁籤

開新頁籤與切到既有頁籤都讓內容區換成那一頁，所以都接到 X9；淘汰哪一個頁籤、新頁籤插在哪裡不跨頁，寫在連線的說明裡。

1. S 點側欄、清單、通知或儀表板上會換頁的項目 → D5（起訖連線，無規格條文；07-02 §業務流程「開啟頁籤」觸發是這個入口）
2. S 按住 Ctrl 或 ⌘、或用滑鼠中鍵點 → X10 瀏覽器的新分頁（起訖連線，無規格條文；不建立工作頁籤；07-02 §業務流程「開啟頁籤」E2；§開啟頁籤與去重 第 5 條；§驗收標準「按住 Ctrl 點擊交給瀏覽器」）
3. D5 是 → X9 那一頁所在的頁籤（切過去，不新開第二個；07-02 §業務流程「開啟頁籤」A1；§開啟頁籤與去重 第 2 條；§驗收標準「同一頁再點一次切到既有頁籤」）
4. D5 否 → D6（07-02 §業務流程「開啟頁籤」主流程第 2 步）
5. D6 是 → X9 新頁籤裡的那一頁（在作用中頁籤的右邊插入新頁籤，掛載那一頁並由網址還原檢視狀態；已達上限時先淘汰最久沒用且沒有未儲存變更的那一個；07-02 §業務流程「開啟頁籤」主流程第 2～3 步、A2；§開啟頁籤與去重 第 3 條；§數量上限與淘汰 第 1、2 條；§驗收標準「新頁籤插在作用中頁籤右邊」「達上限時淘汰最久沒用的」）
6. D6 否 → 留在 P2 目前的頁籤（已有 8 個頁籤且每一個都有未儲存變更：擋下開啟並顯示說明，沒有任何頁籤被動到；07-02 §業務流程「開啟頁籤」E1；§數量上限與淘汰 第 3 條；§驗收標準「全部都有未儲存變更時擋下」）
7. P2 點「重開剛關閉的」或按 Alt+Shift+T → D5（取出最近關閉的一筆重新開啟，再走一次這一段；07-02 §業務流程「關閉與重開頁籤」A1；§關閉與重開 第 3、4 條；§驗收標準「重開剛關閉的頁籤」「重開撞到已開的頁籤」）
8. P2 在某一頁裡切換子分頁或篩選，切換後的狀態和另一個已開的頁籤相同 → X9 那個已開的頁籤（原本的頁籤維持原狀並顯示說明；07-02 §開啟頁籤與去重 第 4 條；§驗收標準「頁內切換撞到已開的頁籤」）

### 分段四：切換與關閉頁籤

1. P2 點另一個頁籤、按 Alt 加數字，或點總覽選單裡的某一列 → D7（07-02 §業務流程「切換頁籤」觸發、主流程第 1～2 步；§頁籤總覽選單 第 6 條；§快捷鍵 第 1 條）
2. D7 是 → X9 目標頁籤的那一頁（由網址還原子分頁、篩選、頁碼與階段，再還原捲動位置；先前載入過的不顯示整頁載入中；07-02 §業務流程「切換頁籤」主流程第 3 步、A1；§切換頁籤與狀態還原 第 1～3 條；§驗收標準「切回頁籤還原子分頁與捲動」「已載入過的頁籤不顯示載入中」）
3. D7 否 → P3 無權限或找不到的畫面（已經沒有權限顯示無權限、任務已被刪掉顯示找不到，頁籤不自動關閉；07-02 §業務流程「切換頁籤」E1；§權限或資料失效 第 1～3 條；§驗收標準「切回時沒有權限」「切回時資料已不存在」）
4. P2 點頁籤的關閉按鈕或按 Alt+W → D8（07-02 §業務流程「關閉與重開頁籤」觸發、主流程第 1 步；§快捷鍵 第 2 條）
5. D8 否 → X9 鄰近頁籤的那一頁（關閉並推進最近關閉的清單；關的是作用中頁籤時，焦點移到緊鄰右邊的頁籤，它是最右邊時移到緊鄰左邊的，內容區跟著換成那個頁籤的頁；07-02 §業務流程「關閉與重開頁籤」主流程第 2～3 步；07-01 §工作頁籤的位置 第 1、2 條；焦點與內容一起換，依 07-01 §工作頁籤的位置 第 4 條的「焦點與目前頁面都不變」把兩者寫成一組，07-02 §不支援的事 第 2 條的「同一時間只顯示一個頁籤的內容」，§驗收標準「Alt+W 關閉作用中頁籤」的「移到下一個頁籤」）
6. D8 是 → 留在 P2（出現該頁原有的確認對話，取消就不關閉，確認之後照分段四第 5 條關閉；07-02 §業務流程「關閉與重開頁籤」E1 的「使用者取消就不關閉」與結果的「有未儲存變更時使用者一定先被問過」；§未儲存保護 第 6 條；§驗收標準「關閉有未儲存變更的頁籤」）
7. P2 點「全部關閉」→ X9 被跳過的其中一個頁籤（關掉所有沒有未儲存變更的頁籤，作用中的被關掉時焦點落在被跳過的頁籤，內容區跟著換成那個頁籤的頁；07-02 §全部關閉 第 1～3 條；§不支援的事 第 2 條；§驗收標準「全部關閉後焦點落在被跳過的」；07-01 §工作頁籤的位置 第 4 條的「焦點與目前頁面都不變」）

### 分段五：無權限與找不到的返回

什麼時候顯示這兩種畫面由各模組自己的規格決定，所以這一段只從畫面本身開始；本模組裡會把人送到這裡的只有分段四第 3 條。

1. P3 按畫面上唯一的返回操作（標籤寫出去處）→ D9（07-03 §畫面的組成 第 1、5 條；§返回操作的去處 第 1 條）
2. D9 是 → X11 各模組指定的去處（例：任務詳情回任務列表、標記清單回儀表板；07-03 §返回操作的去處 第 1、2 條與該節「現況兩例」的註；§已確認決議 Q4）
3. D9 否 → P3（那一頁自己的規則再判一次，顯示的仍是這兩種畫面其中一種；07-03 §返回操作的去處 第 3 條；§邊界情況「返回的去處本身也擋下這個使用者」；§驗收標準「邊界：返回之後仍被擋下」）
