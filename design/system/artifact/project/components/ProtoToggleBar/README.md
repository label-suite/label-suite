原型專用的狀態切換列：固定在視窗底部置中的深色藥丸列，用幾顆 `.proto-btn` 叫出正常操作走不到的頁面狀態。**它不是產品元件**，產品裡不會出現。

## 何時使用

- 只在 `design/prototype/` 的頁面裡，用來切換由後端決定、原型無法自然走到的狀態。目前用在重設密碼與驗證信箱頁，切換「連結可用／已過期／已使用」三種連結狀態。
- 交付包的 `proto-` 狀態前綴就是為它保留的：那幾個狀態不是角色、網址參數、分頁或種子資料能叫出來的。
- 產品實作時整個拿掉，對應的狀態改由真實的 token 驗證結果決定。

## 結構與使用方提供的內容

- `.proto-toggle-bar`：`position: fixed; bottom: 16px; left: 50%` 加水平置中位移，深色半透明底、膠囊圓角。
- 開頭一段說明文字（例如「原型狀態：」）。
- `.proto-btn` 若干顆，各帶 `.active` 或 `.inactive`；按下去呼叫頁面的狀態切換函式（例如 `showState('expired')`）。
- 預覽中為了在卡片裡顯示，以預覽本地的覆寫把它改成 `position: static`，實際頁面裡是固定在底部。

## 變體

只有一種。重設密碼與驗證信箱兩頁的定義完全相同。

## 狀態

| 狀態 | 表現 |
| :--- | :--- |
| `.active` | 目前顯示中的狀態，主色實心 |
| `.inactive` | 其他可切換的狀態，半透明淺色 |
| hover | 背景與文字顏色漸變 |
| focus | 原型沒有（G-05）；因為不是產品介面，不要求補上 |
| 停用／載入中／錯誤／空 | 不適用 |

## 該做／不該做

- **該做**：只在原型頁面使用，並把每個可切換的狀態都列出來，讓審閱者一眼看到頁面有哪些狀態。
- **該做**：接受它沒有 token。底色、圓角、28px 高度、11px 字級全部寫死，是**刻意的例外**：它是原型鷹架，不該和產品共用 token，換主題時也不跟著變（所以兩種主題下長得一樣）。這一點不列入 design gaps。
- **不該做**：把它當成產品的分段控制或篩選器使用，也不要把它的樣式抄進產品元件。
- **不該做**：為它補無障礙需求（如 `aria-pressed`）；它不會出貨。
