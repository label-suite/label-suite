# 規格書

每份規格描述一個頁面或功能的業務規則：目標、使用角色、業務流程、規格、卡控機制、邊界情況、驗收標準與待釐清。
規格由 `spec-writing` skill 產生，只寫業務、不寫技術；狀態為「已定案」的規格才進入 `/opsx:propose`。

- 編號格式：`規格 02-03`（模組編號-頁面編號）
- 業務名詞：見 [術語表](./glossary.mdx)
- 角色、範圍與模組串接：見 PRD（`00-prd.mdx`，撰寫中）
