# Tasks

本 change 沒有 schema 變更、沒有 API 變更、沒有前端變更（`api-contract.md`、`ui-design.md`），所以沒有 `[@dba]` 與 `[@frontend-developer]` task，也不重新產生前端型別；後端群組以「匯出契約確認無差異」收尾。後端指令一律在 `backend/` 以 `uv run` 執行，JavaScript 指令在 repo 根目錄以 `pnpm` 執行；不得出現 pip install 或 npm install。

**不在 worktree 執行 NoteCraft build**（`pnpm exec notecraftapp build docs --rebuild`）：從 worktree 建置會污染主倉庫共用的建置快取，worktree 刪掉後主倉庫的建置會持續失敗。動到 `docs/` 或 `.notecraft/` 的 task 以 `pnpm check:specs` 與 Prettier 檢查收尾，渲染驗證交給 CI 的 `docs-site` job（design D10）。
