# 05 資料集

:ref[專案負責人]{id="term.project-leader"} 與 :ref[審核員]{id="term.reviewer"} 在這個模組看任務的標記統計與品質分析——:ref[IAA]{id="term.iaa"}、被修改率、逐輸出類型的分布；專案負責人另外管資料的匯入與版本。:ref[標記員]{id="term.annotator"} 進不來（PRD §權限矩陣）。

| :--- | :--- | :--- | :--- |

## 這個模組的兩個注意事項

- **05-01 是 IAA 狀態的定名頁**：舊 repo 有兩個同值異名的常數，依 `docs/development/spec-migration.md` 的 D5 統一成一組中文名詞，記在 05-01 的「已確認決議」。05-02 撰寫時沿用、不另立一組。
- **05-03 沒有對應的 prototype 頁面**，依 `spec-writing` 的規則已列入該頁的待釐清（Q1）。它的 §規格 完全不嵌入畫面；來源明寫「本功能不新增獨立頁面」，建立者的入口在規格 03-02 第一步、出口在規格 03-03 的試標發布。
