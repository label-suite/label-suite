# Tasks

本份依 `clarification.md`（Q1–Q12、Q8 補充決議、「交給後續產出」；Q12 取代 Q6、Q10）、`design.md`（D1–D11）與 `specs/` 撰寫。本次**沒有後端群組、沒有 `[@dba]`**：不新增端點、模組、資料表或 migration（`api-contract.md` §端點總覽、`system-design.md` §設計結論），所以也沒有「重新產生 openapi.json」的 task；契約漂移檢查放在最後的整合群組，預期沒有任何差異。

每個前端 task 提交前，該群組動到的部分要通過 `openspec/config.yaml` `operations.apply.guidance` 的前端檢查：`pnpm --filter frontend lint`、`pnpm --filter frontend typecheck`、`pnpm --filter frontend test`、`pnpm --filter frontend build`；動到 `docs/` 時另跑 `pnpm exec notecraftapp build docs --rebuild`，動到 `design/system/` 或 `frontend/src/**` 的元件時另跑 `node scripts/check-component-reuse.mjs`。下列各 task 只寫該 task 自己要看到的測試或結果。

E2E 的範圍：本次只改「移除暫時落點之後，既有 E2E 才不會失敗」所需的部分（群組 7.2）。驗收 specs 用的新 E2E（例如窄螢幕兩欄、角色色隨主題、請求只有 `GET /api/v1/current-session`）屬 `acceptance-verifier`，不列在這裡。
