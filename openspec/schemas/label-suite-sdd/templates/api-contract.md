### 錯誤

| HTTP | 觸發條件 |
| :--- | :--- |
| 400 | 語意或應用規則錯誤 |
| 401 | 未登入，或登入狀態已失效 |
| 403 | 角色或任務成員資格不足 |
| 404 | 資源不存在；**看不到的資源也回 404**，不得用 403 洩漏它存在 |
| 409 | 與目前狀態衝突（例如狀態機不允許） |
| 422 | schema 驗證失敗 |

<!-- 錯誤訊息不得洩漏資源是否存在、不得回傳內部識別碼或堆疊。
     400 與 422 的分界依 api-agent-rules 的 A7：400 是語意或應用規則錯誤、
     422 是 schema 驗證失敗，422 的逐欄位錯誤放回應外層的 errors。 -->
