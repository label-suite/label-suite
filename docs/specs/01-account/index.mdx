# 01 帳號

所有使用者的帳號入口：登入、註冊、忘記與重設密碼、個人設定，以及登入狀態的維持與失效。
帳號本身的管理（新增、停用、指派系統角色）屬系統管理，見 [規格 06-01 使用者管理](../06-admin/01-user-management.mdx)。

## 規格一覽

| 編號 | 頁面／功能 | 狀態 | 說明 |
| :--- | :--- | :--- | :--- |
| 01-01 | [登入](./01-login.mdx) | :badge[草稿]{variant="warning" size="sm"} | Email 與密碼登入，含用 Google 帳號登入的入口 |
| 01-02 | [註冊](./02-register.mdx) | :badge[草稿]{variant="warning" size="sm"} | 自行填寫姓名、Email 與密碼建立帳號，成為平台成員 |
| 01-03 | 忘記與重設密碼（未撰寫） | — | 忘記密碼時用 Email 重設 |
| 01-04 | 個人設定（未撰寫） | — | 編輯個人資料、變更 Email 與修改密碼 |
| 01-05 | 登入狀態與安全（未撰寫） | — | 登入狀態的維持、登出與失效 |
