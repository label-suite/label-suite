無框的膠囊標籤，顯示一筆填答的提交狀態：已提交、已儲存、未開始。

## 何時使用

- 標註者清單、題目清單上，標示每一筆作答目前存到哪一步。
- 任務本身的狀態用 Badge，不用 Status Pill；兩者外觀相近，但是不同的元件。

## 結構與使用方提供的內容

- `.status-badge` 加一個狀態類別，內容是狀態文字。
- 沒有框線，圓角 `--radius-full`，字重 700，底色用對應語意色的 `-soft-bg` token。
- 全部用 token，沒有寫死值，暗色主題自動跟著換。

## 變體

| 類別 | 文案 | 意義 |
| --- | --- | --- |
| `.status-submitted` | 已提交 | 已送出，不再修改 |
| `.status-saved` | 已儲存 | 存了草稿，還沒送出 |
| `.status-pending` | 未開始 | 還沒有作答 |

## 狀態

- 靜態，沒有互動狀態。
- 狀態改變時由頁面換類別與文字。
- 流向只有一條：未開始 → 已儲存 → 已提交；已提交之後不會回到已儲存。
- 暗色主題下 `-soft-bg` 與文字色都由 token 換成暗色組，不需要額外樣式。

**與 Badge 的差別**

| | Status Pill | Badge |
| --- | --- | --- |
| 描述的對象 | 一筆作答 | 任務、角色、型別 |
| 外框 | 無 | 有 |
| 字重 | 700 | 一般 |

## 該做／不該做

- 該做：文案與類別一對一，不要只換顏色不換字。
- 該做：放在同一欄、同一位置，方便掃視。
- 不該做：拿它表示任務狀態或角色；那是 Badge。
- 不該做：加框線或改成方角，讓它和 Badge 混在一起。
