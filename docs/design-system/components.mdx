# 元件對照

每個元件有三處：元件規格是依據，Artifact 的元件資料夾是從規格濃縮出的呈現，prototype 原始檔是規格依據的現況。三者不一致時以 prototype 現況與 `design/system/` 的規格為準，Artifact 重新產生。

| 位置 | 角色 | 能不能直接改 |
| :--- | :--- | :--- |
| `design/prototype/` | 畫面現況，規格的證據 | 改畫面走 `AGENTS.md` 的 Ready gate |
| [`design/system/components/<元件>.md`](../../design/system/components/) | 元件規格：結構、變體、狀態、token、鍵盤與焦點、樣式出處 | 由 `design-system-setup` 維護 |
| [`design/system/artifact/project/components/<元件>/`](../../design/system/artifact/project/components/) | Artifact 的元件說明（`README.md`）與樣本（`preview.html`） | 改這裡，再重新發布；線上改的不算（見 [設計交接](../development/workflow/design-handoff.mdx#單向規則)） |

## 只在 Artifact 的檔案

| 檔案 | 是什麼 |
| :--- | :--- |
| `Cover/` | Artifact 的封面，沒有對應的元件規格 |
| `bundle.css` | 全部元件樣式的合併檔，樣式抄自 `design/prototype/pages/shared/*.css` 與 `components-showcase.html` 的正典區塊，不重新調色 |

新增或改名一個元件時，規格檔、Artifact 資料夾與 `bundle.css` 一起改，再更新這張表；順序與重新發布的時機見 [設計交接](../development/workflow/design-handoff.mdx#什麼時候重跑哪一步)。
