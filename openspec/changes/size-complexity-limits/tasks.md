# Tasks

本 change 沒有 schema 變更、沒有 API 變更、沒有畫面變更（`api-contract.md`、`ui-design.md`、system-design §資料模型異動），所以沒有 `[@dba]` task，也不重新產生 `openapi.json` 與前端型別；動到 `frontend/`、`backend/` 的群組仍以契約漂移指令確認「沒有差異」收尾。JavaScript 指令在 repo 根目錄以 `pnpm` 執行，Python 在 `backend/` 以 `uv`；不得出現 npm install 或 pip install，本 change 不新增任何相依套件。

**提交規則**：每個群組完成後提交一次，訊息依 AGENTS.md §Commits（`<type>: <subject> (#561)`、body 每點以粗體動詞開頭、動詞後不加冒號），結尾**恰好一個** `Co-Authored-By` trailer 標明模型。commit 被 hook 擋下時修正後重新 `git commit`，**不得** `--amend`；push 前以 `git log origin/main..HEAD` 確認只有本分支的 commit。各組的「故意弄壞再還原」以暫時修改做，還原後 `git diff` 只剩本 task 的改動，指令與結果記在該組的提交訊息。

**不在 worktree 執行 NoteCraft build**（`pnpm exec notecraftapp build docs --rebuild`）：從 worktree 建置會污染主倉庫共用的建置快取。動到 `docs/` 的 task 以 `node scripts/check-specs.mjs docs`、`node scripts/check-citations.mjs --strict` 與 `pnpm format:check` 收尾，渲染驗證交給 CI 的 `docs-site` job。

第 1、2 組改不同的檔案、互不依賴，順序可對調；第 3 組寫的是第 1、2 組已成立的行為，排在最後。
