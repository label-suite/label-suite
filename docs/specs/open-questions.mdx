# 待釐清彙總

搬移舊 repo 規格時，單頁的決策一律寫進各頁的「待釐清」章節，並同步到這裡。
這一頁是工作清單：從上往下決定，決定完的題目由第二輪折回該頁的「已確認決議」，並從這裡移除。
清單空了代表 17 頁全部定案，可以開始跑 `/opsx:propose`。

做法與十條跨頁決議見 [搬移設計文件](../development/spec-migration.md)。
各頁原生的「待釐清」章節仍然是正式位置，這裡只是入口。
