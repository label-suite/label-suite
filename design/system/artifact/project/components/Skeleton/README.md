載入中的佔位骨架，形狀與尺寸對齊即將出現的內容，避免載入完成時版面跳動。

## 何時使用

- 資料在載入、但版面結構已知時：卡片清單、表單、個人資料。
- 載入完成後畫面「長得一樣、只是填進資料」時最有用（UXC-08）。
- 不知道會載入多少內容、或只是一瞬間的操作，用按鈕的 loading 狀態即可。

## 結構與使用方提供的內容

**A pulse（卡片、清單版面）**

- `.skeleton-stack` > `.skeleton-card` > `.skeleton-line`。
- 線條寬度用 `.title`、`.body`、`.short` 區分；底色用 `--color-border`。

**B shimmer（表單版面）**

- `.skeleton` 加上形狀類別：`.skel-avatar`、`.skel-line`、`.skel-input`、`.skel-btn`。
- 使用方依實際表單排出對應的欄位數與順序。

兩種都要在外層容器加 `aria-busy="true"`，載入完成後拿掉；需要時搭配 `aria-live` 宣告載入完成。

## 變體

- A pulse：透明度脈動，給卡片與清單。
- B shimmer：由左至右的光澤掃過，給表單。漸層顏色與固定 1.5s 週期目前寫死（G-02）。

## 狀態

- 載入中：顯示骨架，容器 `aria-busy="true"`。
- 完成：整塊換成真實內容，不保留骨架。
- 失敗：換成 State Panel 或 Empty State 的錯誤樣式，不要讓骨架一直轉。
- 減少動態：個人資料頁缺 `prefers-reduced-motion` 的處理（G-30），新用法要讓動畫在該設定下停住。

## 該做／不該做

- 該做：骨架的高度、寬度、數量對齊載入後的內容（UXC-08）。
- 該做：同一個區塊只用一種變體。
- 不該做：在骨架上放文字或「載入中…」字樣，再疊一個 spinner。
- 不該做：把 B 的寫死漸層複製到新地方；需要新色時用 token 並回報 G-02。
