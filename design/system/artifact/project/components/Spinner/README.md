送出中的旋轉圈：放在實心送出鈕裡、取代按鈕文字的 18×18 `<span class="spinner">`，以 0.7 秒一圈持續旋轉。

## 何時使用

- 帳號頁（登入、註冊、忘記密碼、重設密碼）按下送出、等待伺服器回應的那段時間。
- 行為契約 UXC-06：送出中要有載入態，並防止重複送出。
- 載入一整塊內容時不用它，用 Skeleton；一般按鈕的載入中用 [Button](../Button/README.md) 的 `.btn-loading`。設計系統正典的載入語彙是這兩者，旋轉圈是帳號頁自己加的。

## 結構與使用方提供的內容

- 單一 `<span class="spinner">`：18×18、2.5px 邊框、頂邊換色、`border-radius: 50%`，以 `@keyframes spin` 旋轉。
- 放在送出鈕內，取代原本的按鈕文字。
- 使用方提供 `aria-label="載入中"`（或對應語言的文字），並讓外層按鈕帶 `aria-busy="true"` 與 `disabled`。
- 目前樣式只定義在帳號頁範圍內，需放在 `.auth-page` 裡。

## 變體

- 只有一種外觀，但帳號頁有兩份定義：登入、忘記密碼、重設密碼是一份，註冊是另一份（G-28：帳號頁元件定義分歧）。重建時合為一份。
- 驗證信箱頁沒有表單送出，所以沒有旋轉圈。

## 狀態

| 狀態 | 表現 |
| :--- | :--- |
| 旋轉中 | 唯一的狀態 |
| 減少動態 | 使用者開啟 `prefers-reduced-motion: reduce` 時，動畫時間被壓到 0.01ms，圈停住不轉 |
| 其他 | 不適用 |

G-31：註冊、忘記密碼、重設密碼三頁的送出中狀態沒有被收為可重現的畫面，目前只有登入頁能直接看到。

## 該做／不該做

- **該做**：同時停用外層按鈕並加 `aria-busy`，避免重複送出（UXC-06）。
- **該做**：保留減少動態的處理。
- **該做**：實作時改成繼承 `currentColor` 的圖示或以 token 上色。原型的頂邊是 `--color-on-cta`，其餘三邊是 40% 的 `--color-on-cta`（#437 之前是寫死的半透明白），只適用於「`--color-on-cta` 字的實心 CTA 鈕」；深色主題下兩者都換成深墨色。
- **不該做**：把它放在淺底或外框按鈕上，淺色主題下白色會看不見。
- **不該做**：用它代替整塊內容的載入骨架。
