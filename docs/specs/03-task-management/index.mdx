## Logic Flow

任務管理的三頁是一條幹道：側欄把人送進任務列表，列表再分岔成「新增任務」與「任務詳情」兩條支線，而兩條支線做完或被擋下時大多回到任務列表。通往別的模組的出口有四個：任務詳情的最終例外池單向進標記工作區（[規格 03-03](./03-task-detail.mdx#最終例外池) §最終例外池 的「進入處置畫面」，第 6 條）；權限矩陣「檢視任務列表」那一格不允許的人被帶回儀表板（[規格 03-01](./01-task-list.mdx#誰看得到哪些任務) §誰看得到哪些任務 的「無權限檢視任務列表」，第 7 條）；成員管理的 Email 邀請把受邀者送到帳號模組的登入頁（[規格 03-03](./03-task-detail.mdx#成員管理) §成員管理 的「受邀者點信裡的連結 → 落在」，第 11 條）；在新增任務時點側欄離開，到他點的那一頁（[規格 03-02](./02-task-new.mdx#離開這一頁與重新整理) §離開這一頁與重新整理 第 2 條與該節補充條）。被擋下的人落在哪裡要看是哪一種擋法：依[規格 03-03](./03-task-detail.mdx#誰進得來誰看得到哪些分頁) §誰進得來、誰看得到哪些分頁 的「帶回任務列表」（第 1 條），沒有角色的人被帶回任務列表，而同節第 4 條說權限被撤銷的人留在任務詳情看一張無權限面板；任務不存在或已封存時也留在任務詳情，內容區換成找不到的畫面（[規格 03-03](./03-task-detail.mdx#共用任務標頭) §共用任務標頭 的「沿用找不到任務的呈現」，第 8 條）。沒有建立任務權限的人被帶回任務列表（[規格 03-02](./02-task-new.mdx#卡控機制) §卡控機制 的「無權限建立任務」），建立失敗的人留在新增任務的第四步（[規格 03-02](./02-task-new.mdx#建立任務) §建立任務 的「留在第四步」，第 3 條）。

這一節只畫頁面之間怎麼走，以及決定往哪一頁走的判斷；同一頁裡的操作細節看各規格的業務流程。連線依方向分三類判：離開本模組一律畫，進入與返回只在本模組自己的規格定了那個入口、或定了「回來之後這一頁顯示什麼」時才畫，模組內兩頁之間的移動本來就要畫。每一條連線都對回規格的條文，規格裡找不到出處的連線不畫（這個模組目前每條連線都找得到出處，所以沒有缺口摺疊區塊）；三類判準逐條盤點的結果，列在本節最後那個摺疊區塊。唯一沒有規格出處的是起訖連線（S 接上的那兩條），它只標出流程從哪裡開始。這個模組沒有 E 結束節點：使用者在任務列表、新增任務與任務詳情三頁之間來回，通往別的模組的三個出口——最終例外池進標記工作區（P3 → X2）、被擋下回儀表板（D1 否 → X3）、邀請信把受邀者送到登入頁（X4 → X5）——都是單向離開，不是模組的自然終點。

### 分段一：進入任務列表與分岔

1. X1 側欄點「任務管理」→ D1（07-01 §導覽項目與可見性 第 1 條與該節「任務管理對 03」的註；03-01 §業務流程「進到任務列表」觸發）
2. D1 是 → P1 任務列表（03-01 §業務流程「進到任務列表」主流程第 1～3 步；§誰看得到哪些任務 第 6、8 條）
3. P1 點任務列或那一列的「編輯」→ D2（03-01 §點任務進入任務詳情 第 1、2 條；§業務流程「從列表進入任務詳情」主流程第 1～2 步）
4. D2 是 → P3 任務詳情（03-01 §點任務進入任務詳情 第 1、2 條；§業務流程「從列表進入任務詳情」主流程第 3 步；03-03 §業務流程「進入任務詳情」觸發、主流程第 2～3 步）
5. D2 否 → 停在 P1（顯示「無權限檢視任務詳情」，不跳頁；03-01 §點任務進入任務詳情 第 3 條；§業務流程「從列表進入任務詳情」E1；§卡控機制「使用者點的任務他看不了詳情」；§驗收標準「沒有權限時停在列表」）
6. P1 點「新增任務」→ P2 新增任務（03-01 §新增任務 第 1、2 條；§業務流程「從列表進入任務詳情」A1；§驗收標準「點新增任務」）
7. D1 否 → X3 儀表板（被帶回儀表板並顯示「無權限檢視任務列表」；03-01 §誰看得到哪些任務 第 7 條；§已確認決議 Q23；§驗收標準「那一格關掉就進不來」「那一格缺列也進不來」）

### 分段二：新增任務這條單行道

四個步驟之間的往返（「下一步」「上一步」與每一步各自的過關條件）不跨頁，不畫成連線；規則在[規格 03-02](./02-task-new.mdx#四個步驟) §四個步驟 與各步驟自己的節。

1. P1 點「新增任務」→ D3（03-01 §新增任務 第 1 條；03-02 §業務流程「填完基本資料」觸發與前置條件）
2. S → D3（起訖連線，無規格條文；03-02 §邊界情況「沒有建立任務權限的人直接打開這一頁」是這個入口）
3. D3 是 → P2 新增任務的第一步（03-02 §業務流程「填完基本資料」主流程第 1 步；§四個步驟 第 1～3 條）
4. P2 四個步驟都過關、點「建立任務」→ D4（03-02 §建立任務 第 1 條；§業務流程「建立任務」主流程第 2 步；§四個步驟 第 4 條）
5. D4 是 → P3 任務詳情（03-02 §建立任務 第 2 條；§業務流程「建立任務」主流程第 3 步與結果；§驗收標準「建立成功後前往任務詳情」）
6. D3 否 → D1（被帶回任務列表並顯示「無權限建立任務」；03-02 §卡控機制 前兩列；§邊界情況「沒有建立任務權限的人直接打開這一頁」；§驗收標準「沒有權限的人進不來」；§已確認決議 Q18。回到任務列表時由那一格再判一次，依 07-03 §返回操作的去處 第 3 條；允許就落在 P1，不允許就到 X3 儀表板，依 03-01 §誰看得到哪些任務 第 7 條，即分段一第 7 條）
7. D4 否 → 留在 P2 的第四步（整件事回到原狀，已填的內容都保留，顯示失敗說明，可以再點一次「建立任務」；03-02 §建立任務 第 3 條；§業務流程「建立任務」E1；§驗收標準「建立失敗後留在第四步」；§已確認決議 Q19）

### 分段三：中途離開新增任務

選「繼續編輯」留在原處，以及按 F5 還原到原本那一步並回填已填資料，都不跨頁，不畫（[規格 03-02](./02-task-new.mdx#離開這一頁與重新整理) §離開這一頁與重新整理 第 3、4 條）。

1. P2 點「取消」，或要離開這一頁（點側欄、關分頁）→ D5（03-02 §離開這一頁與重新整理 第 1 條；§業務流程「中途離開或重新整理」主流程第 1～3 步）
2. D5 是 → P1 任務列表（點「取消」、改過東西：顯示「離開此頁面？」，選「離開」就回到任務列表、不建立任務；03-02 §離開這一頁與重新整理 第 1、2 條；§業務流程「中途離開或重新整理」主流程第 4～5 步；§驗收標準「選離開就不建立任務」）
3. D5 否 → P1 任務列表（點「取消」、完全沒有改過任何東西：不跳確認，直接回到任務列表；03-02 §離開這一頁與重新整理 該節補充條「完全沒有改過任何東西時，點「取消」或離開不會跳確認」；§業務流程「中途離開或重新整理」A2；§邊界情況「什麼都沒填就點「取消」」）
