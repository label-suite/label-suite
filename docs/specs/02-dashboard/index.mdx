# 02 儀表板

登入後的第一頁。系統依使用者在各任務的角色給他一種對應的版面，把他的任務彙整在一起，並讓他一步回到標記或審核。

這個模組**只讀不寫**：PRD §權限矩陣 給儀表板的只有 `R`。它顯示的數字來自 03 任務管理、04 標記作業與 05 資料集，計算規則由那些模組擁有。
