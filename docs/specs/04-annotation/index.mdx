## 這個模組的一份來源拆成兩頁

兩頁共用同一份舊規格（`specs/annotation/015-annotation-workspace/spec.md`，**517 條**，18 份裡最大的一份）。依 `docs/development/spec-migration.md`，同一個舊編號只能落在其中一頁，另一頁的對照表寫「見 規格 04-0X」。分頁歸屬由 04-01 的最後一個階段決定，並留言到 Issue #78 讓 04-02 可以機械對帳。
