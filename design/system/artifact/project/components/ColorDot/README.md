小色塊，標示一個實體類別或一筆資料系列的顏色；顏色由資料決定，不是介面色。

## 何時使用

- 標註設定裡，每個實體類別的代表色。
- 標註預覽裡，標出文字片段的類別色。
- 圖表或清單旁的小圖例（例如 IAA 達標／未達標）。

## 結構與使用方提供的內容

| 類別 | 尺寸 | 用途 |
| --- | --- | --- |
| `.entity-color-dot` | 20px，圓角 `--radius-sm` | 實體類別設定 |
| `.annotation-preview-color` | 12px，圓角 3px | 標註預覽 |
| `.t-dot` | 8px 圓點 | 圖例 |

- 顏色由使用方以行內 `style="background: …"` 給，值來自資料。
- 預設八色調色盤屬於資料色，不是設計 token（G-02）。
- 外框的 rgba 在暗色主題下不變。
- 同一個類別在所有畫面用同一個顏色：設定頁的 `.entity-color-dot` 與預覽裡的 `.annotation-preview-color` 讀的是同一筆資料。

```html
<span class="entity-color-dot" style="background: #6366f1" title="人名"></span>
<span>人名</span>
```

上面的色碼是資料，不是 token；實際值由任務設定提供。

## 變體

- 三種尺寸如上表，沒有其他變體。

## 狀態

- 靜態，沒有互動狀態。
- 目前用 `title` 說明顏色代表什麼；`title` 不等於 `aria-label`，報讀器不一定唸，而且顏色是唯一的線索（G-14）。

## 該做／不該做

- 該做：色塊旁一定有文字標籤（類別名稱），不要只靠顏色。
- 該做：需要給報讀器時加 `aria-label` 或可見文字，不要只放 `title`。
- 不該做：用介面語意色（成功、錯誤）當資料色，兩者會互相混淆。
- 不該做：把八色調色盤寫進新的 CSS；它是資料，由設定提供。
