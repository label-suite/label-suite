# 05 資料集

:ref[專案負責人]{id="term.project-leader"} 與 :ref[審核員]{id="term.reviewer"} 在這個模組看任務的標記統計與品質分析——:ref[IAA]{id="term.iaa"}、被修改率、逐輸出型別的分布；專案負責人另外管資料的匯入與版本。:ref[標記員]{id="term.annotator"} 進不來（PRD §權限矩陣）。

## 規格一覽

| 編號 | 頁面／功能 | 狀態 | 說明 |
| :--- | :--- | :--- | :--- |
| 05-01 | [分析列表](./01-analysis-list.mdx) | :badge[草稿]{variant="warning" size="sm"} | 模組入口：列出自己有分析權限的任務；**IAA 狀態的定名頁**、32 條舊編號全數對應 |
| 05-02 | [分析詳情](./02-analysis-detail.mdx) | :badge[草稿]{variant="warning" size="sm"} | 統計總覽與品質監控（含 IAA）；**分五個階段寫**，目前階段一（外殼與雙分頁）與階段二（統計總覽）已寫完 |
| 05-03 | 資料匯入與版本（未撰寫） | — | 追溯每筆資料的來源與資料集版本 |

## 這個模組的兩個注意事項

- **05-01 是 IAA 狀態的定名頁**：舊 repo 有兩個同值異名的常數，依 `docs/development/spec-migration.md` 的 D5 統一成一組中文名詞，記在 05-01 的「已確認決議」。05-02 撰寫時沿用、不另立一組。
- **05-03 沒有對應的 prototype 頁面**，依 `spec-writing` 的規則要列入該頁的待釐清。
