在 zh-TW 與 EN 之間切換整頁語言的按鈕：一個 `<button class="lang-toggle">`，內含地球圖示與目前語言代碼。

## 何時使用

- 登出狀態的帳號頁（登入、註冊、忘記密碼、重設密碼、驗證信箱）右上角的語言切換。
- 登入後不用它：側欄與行動版各有自己的語言鈕，屬於 App Shell。
- 正典名稱是 `.btn-language`。依維護者 2026-11-17 的裁定（G-03），`.lang-toggle` 與 `.btn-language` 是同一個元件，新畫面用 `.btn .btn-language`；帳號頁的 `.lang-toggle` 是同一元件的既有寫法，預覽兩者並列供對照。

## 結構與使用方提供的內容

- 一個原生 `<button>`，帶 `aria-label="切換語言"`。
- 內容：地球 `<svg>`（`aria-hidden`）＋目前語言代碼文字（`ZH`／`EN`）。
- 帳號頁的寫法需放在 `.auth-page` 範圍內，樣式才會套用。
- 使用方提供切換後的文案表：按下去**不只換這顆鈕**，整頁文案都要依目前語言重新套用，所以它實際上是頁面層級的控制項。

## 變體

只有一種：兩種語言之間的切換。

- 五個帳號頁的 `.lang-toggle` 規則完全相同，是帳號頁唯一沒有分裂的元件（其餘帳號頁元件的分歧見 G-28）。
- 若日後支援超過兩種語言，應改成下拉選單，而不是讓這顆鈕循環切換。

## 狀態

| 狀態 | 表現 |
| :--- | :--- |
| 預設 | `--color-card` 底、`--color-border` 外框、`--radius-md` 圓角，文字 `--color-ink-muted` |
| 切換後 | 文字換成另一個語言代碼，整頁文案同步更新 |
| hover | 原型未定義，需逐頁確認 |
| focus | **原型沒有**焦點樣式（G-05），實作時補上焦點環 |
| 停用／載入中／錯誤／空 | 不適用 |

## 該做／不該做

- **該做**：保留 `aria-label="切換語言"`；切換後連同其他元件的動態無障礙名稱一起重算（例如密碼眼睛的「顯示密碼／隱藏密碼」）。
- **該做**：新程式碼用正典名 `.btn-language`（G-03）。
- **不該做**：另外再寫一份語言鈕的樣式；`.lang-toggle` 與 `.btn-language` 目前沒有共用程式碼，重建時要合為一份。
- **不該做**：只換這顆鈕的文字而不換整頁文案。
