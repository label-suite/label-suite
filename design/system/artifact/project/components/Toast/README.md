浮在畫面上的短訊息，回報一個動作的結果；每頁只有一個容器，新訊息直接取代舊訊息。

## 何時使用

- 回報剛做完的動作：儲存成功、背景工作已開始、部分資料尚未載入、儲存失敗。
- 結果不需要使用者留在某張表單上修正時。表單還在、要就地修正的錯誤用 Alert Banner；表單被結果整個取代時用 State Panel。

## 結構與使用方提供的內容

- 每頁一個 `#toast` 容器，帶 `aria-live="polite"` 與 `aria-atomic="true"`；平常隱藏，加 `.visible` 才出現。
- 容器裡放一張 `.toast-card`，加 variant 類別（`success`、`info`、`warning`、`error`）。
- 卡片內容：一句訊息加一個關閉按鈕。關閉按鈕用 `assets/icons/` 的 x 內嵌 SVG，並給 `aria-label="關閉"`。
- 新訊息用 `replaceChildren` 取代舊卡片，不排隊、不堆疊。
- 寬度 `min(384px, calc(100vw - 32px))`；陰影用 `--shadow-md`，這是扁平風格下核准的例外。

## 變體

| 變體 | 自動關閉 | 用途 |
| --- | --- | --- |
| `success` | 3000 ms | 動作成功 |
| `info` | 5000 ms | 背景工作開始、提示 |
| `warning` | 8000 ms | 部分成功、需要留意 |
| `error` | 0（不自動關閉） | 失敗，使用者手動關閉 |

## 狀態

- 隱藏 → `.visible` 出現 → 時間到或按關閉後移除 `.visible`。
- hover 不會暫停計時（G-09）。
- 出現時不搬移焦點；error 一直停留，但用鍵盤不容易走到它的關閉鈕（G-08）。
- Escape 不會關閉它。
- 預覽把固定定位改成 `position: static` 才能並排展示，實際頁面是固定在畫面上的。

## 該做／不該做

- 該做：依 variant 給對應的停留時間，失敗訊息一律不自動消失。
- 該做：訊息一句話講完結果，必要時再接下一步。
- 不該做：同時顯示多張 toast，或自己做佇列。
- 不該做：各頁再寫一份 toast（G-10 記錄了現況各頁重做的問題），也不要寫死同一個停留時間（G-39）。
- 不該做：用 toast 放需要使用者閱讀或操作很久的內容。
