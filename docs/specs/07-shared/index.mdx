# 07 共用介面

所有登入後的頁面共用的外框：側欄導覽與工作頁籤。每一個使用者都會用到，所以這個模組的術語與角色寫法是其他模組的基準。
兩個頁面都不是獨立頁面，它們的畫面出現在每一個模組頁裡。

## 規格一覽

| 編號 | 頁面／功能 | 狀態 | 說明 |
| :--- | :--- | :--- | :--- |
| 07-01 | [側欄導覽](./01-sidebar.mdx) | :badge[草稿]{variant="warning" size="sm"} | 各頁共用的側欄、語言與外觀切換、通知、快捷鍵總覽、登出 |
| 07-02 | [工作頁籤](./02-workspace-tabs.mdx) | :badge[草稿]{variant="warning" size="sm"} | 同時保留多個頁面的檢視狀態並快速切換；試標與正式標記的比對基礎 |
