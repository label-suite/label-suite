### 錯誤

| HTTP | 觸發條件 |
| :--- | :--- |
| 400 | 欄位驗證失敗 |
| 401 | 未登入，或登入狀態已失效 |
| 403 | 角色或任務成員資格不足 |
| 404 | 資源不存在；**看不到的資源也回 404**，不得用 403 洩漏它存在 |
| 409 | 與目前狀態衝突（例如狀態機不允許） |
| 422 | 語意上無法處理的輸入 |
